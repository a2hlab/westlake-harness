## Intent
Build one traceable native candidate over the signed generation specified by the task (currently U8), retaining the signed Java and boot-image group.
## Constraints
- Work offline; no device commands or board writes in this contract.
- Keep R155 libart and bridge 846 unchanged; retain all frozen API implementations.
- Reuse audited donors with their applicability limits; no error/null stub may be reported as a functional implementation.
- Preserve strict native predeployment gates and request explicit, identity-bound exceptions for unresolved findings.
