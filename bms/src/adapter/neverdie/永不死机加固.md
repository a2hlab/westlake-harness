## 1. 为什么需要它(核心心智模型,别搞混)

`/data/adapter` 是 **Android-OpenHarmony 源码+构建工作区**,不是 daemon。它已有一个 `restore_after_sync.sh`,但二者守护的东西不同、互补:

| | 守护对象 | 死了怎么救 |
|---|---|---|
| `restore_after_sync.sh`(早就有) | `~/aosp/`、`~/oh/` 源码树 | 用 adapter 的权威输入(patches/framework/build…)**重建**进去 |
| **`neverdie/`(本增强)** | adapter 自己的**权威输入**(上面那批「弹药」) | 用 golden 快照**回滚**它们 |

**缺口**:`restore_after_sync.sh` 的弹药本身没人保护。一次坏 edit / 坏 patch / 坏 `repo sync` / 误删,一键恢复自己就「死机」。`neverdie/` 补的就是这个。

对应 16.16 的能力:**R3/R13** golden A/B 双 slot · **R2** 失败计数兜底 · **R17** 磁盘配额 · **R14** metrics/log。(R1 watchdog 不适用——无长驻进程。)

## 4. 怎么用(命令速查)

```sh
cd /opt/10.Project/16-WestLake/16.12-HanBing/adapter   # GZ05 上是 cd /data/adapter

bash neverdie/nd_verify.sh           # 体检:0=健康 1=被改 2=没golden
bash neverdie/nd_backup_golden.sh    # 改对了、设为新基线时重拍
bash neverdie/nd_restore_golden.sh   # 出事回滚(交互确认);无人值守加 --force
bash neverdie/nd_guard.sh --status   # 看 active slot / 失败计数 / metrics

# 接进编译流程(推荐)
bash restore_after_sync.sh && <build 命令> \
    && bash neverdie/nd_guard.sh --mark-success \
    || bash neverdie/nd_guard.sh --build-failed
```

`--mark-success` = 清零失败计数 **并自动拍一张新 golden**(把当前 known-good 设为新基线)。

## 5. 三个必须知道的设计决定(别踩坑)

1. **白名单,不是黑名单**。只快照 `ND_PROTECT` 里列的权威输入:
   `framework/ aosp_patches/ ohos_patches/ build/ app/ appspawn/ config/ deploy/ doc/` +
   `CLAUDE.md readme.txt build.sh bundle.json restore_after_sync.sh appspawn_x_design.html`。
   → `out/`(1.9G)、`oh-build-*.tar.gz`(397M)、`prebuilts/`、`build/out`、`*.log` **天然全排除**。
   **正因如此,即使 OH 大文件还在复制中,也能安全快照**(已验证:复制只动排除区)。
   要加保护项就改 `nd_common.sh` 的 `ND_PROTECT`,改完重拍 golden。

2. **golden 仓库刻意在 `adapter/` 之外**(默认 `../.adapter-neverdie`):扛得住整个 `adapter/` 被删,且不进 Local↔ECS 同步。
   **GZ05 上必须设** `export ND_GOLDEN_ROOT=/data/.adapter-neverdie`(否则默认会落在 `/data/.adapter-neverdie`,其实也对;但显式设更稳,建议写进 `~/.bashrc`)。

3. **默认不自动覆盖手写输入**。inputs 是手写弹药,连续 build 失败更可能是代码 bug 而非文件损坏。达阈值(`ND_FAIL_THRESHOLD`,默认 3)时默认只**响亮告警**;要无人值守自动回滚才设 `ND_AUTO_RESTORE=1`。

可调环境变量:`ND_GOLDEN_ROOT` / `ND_ADAPTER_ROOT`(演练指副本)/ `ND_FAIL_THRESHOLD` / `ND_AUTO_RESTORE` / `ND_MAX_CORRUPT_COPIES` / `ND_MAX_GOLDEN_ROOT_MB`。

bash "$ND_DIR/nd_restore_golden.sh" --force >/dev/null

bash "$ND_DIR/nd_verify.sh" >/dev/null; echo "restored rc=$?" # 期望 0
rm -rf "$T" "$T-g"
