##187+adc is a hypothesis, not a passed replacement

Both exact artifacts were hashed locally. The187 runtime retains full registrations; adc is used only at libandroid, never as the runtime substitute.187 restores old fixed-panel BBQ stamp behavior, while adc preserves the Unity-facing handoff and width0 semantics. This is positive static support for an A/B, not proof it will keep Boat playable:187 also has its own fixed geometry calls and later Java updates can overwrite the landscape buffer. Exact symbol owner and temporal ordering remain unknown. Previous stock rendering is not input/steering/LAP proof. Existing947+adc window3 input approval does not transfer.
