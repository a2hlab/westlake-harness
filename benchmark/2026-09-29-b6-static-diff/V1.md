# B6 task 53: R155 versus task 50, offline static comparison

The previous assumption to reject is that these candidates differ only in link order. All six assigned hashes match, but NEW also adds host stdio interposition, replaces child acquisition/identity paths, and changes provider VM initialization. Static evidence establishes these differences; it does **not** establish which one caused a device failure. No device command was issued. Commit is delegated to the outer loop.

This first edition covers ELF dynamic metadata, symbols and strings. Function comparison and final dispositions follow in the second edition. `restore-review` means a conservative R155-parity candidate requiring function review, **not** proven faulty code. Do not deploy the entire list as a single untested change.

## First-edition restoration candidates

1. **Host loader order: restore.** Move `libhilog.so` from first to after `libsec_shared.z.so`; the other 11 dependencies retain relative order. SONAME, RUNPATH absence, FLAGS and FLAGS_1 are unchanged for all three pairs. Evidence: `evidence/host/r155/dynamic.txt:4` and `evidence/host/new/dynamic.txt:4`. This is the isolated experiment already owned by #52.
2. **Host stdio binding: restore/review next.** NEW defines `__sF`, `fflush`, `fprintf`, `fputc`, `fputs`, `fwrite`, `vfprintf`; R155 imports `fflush`/`vfprintf`. NEW imports `pthread_once`, `stderr`, `stdin`. This changes the dynamic symbol surface and warrants a distinct parity experiment. Evidence: `evidence/host/metadata-diff.json` imports/exports, plus full `symbols.txt` dumps.
3. **Child namespace/identity protocol: review as a unit.** `WLSCPL_InheritAndroidRuntimeV1` is new; imports switch away from `dlopen`/`dlclose` toward `dlns_inherit`, time/random/identity helpers. New strings include `WLSCPL-MANIFEST-V2`, boot ID, A02 prerequisites and A06 bundle messages. This is not just rebuilding the original loader. Evidence: `evidence/child/metadata-diff.json` and `strings-diff.json`.
4. **Provider VM startup: high-priority restoration review.** NEW removes `ZygoteHooks`/post-fork method strings and adds non-zygote specialized-child mode, Java `System.loadLibrary("javacore")`, Typeface warmup override and deferred Java adapter initialization. R155 environment strings `ANDROID_I18N_ROOT`, `ANDROID_TZDATA_ROOT`, `ICU_DATA`, `DEX2OATBOOTCLASSPATH` disappear. Whether equivalent work moved into other generation files is outside this three-file static proof. Evidence: `evidence/runtime-provider/strings-diff.json`.
5. **Provider dependency/constructor growth: restore/review together with startup.** NEW adds `libwestlake_art_abort_bridge.so` before `libart.so`, adds `libbase.so` after it, and adds `_GLOBAL__sub_I_westlake_android_runtime_provider.cpp` to `.init_array`. Other resolved init/fini targets retain order. Evidence: provider `dynamic.txt`, `relocations.txt`, and inventory arrays.
6. **Do not revert address shifts or generation hashes in isolation.** Host TLS is still 48 initialized zero bytes, alignment 16, flags R; only offsets/addresses shift. Child/provider still have no PT_TLS. Host constructor targets remain `__do_init`, `_init`; fini remains `__on_dlclose_late`, `__do_fini`. Route-a generation and child/provider hash strings must match the chosen artifact generation. Debug paths, symbol-table locations, build IDs and section offsets are not behavioral evidence by themselves.
