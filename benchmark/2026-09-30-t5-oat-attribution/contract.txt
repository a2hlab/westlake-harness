# Task Contract: Attribute T5 OAT key-value and checksum differences

## Intent
Audit the premise that the R155 reference contains missing bootclasspath-checksums metadata. Compare available T5 OAT headers, key-value stores and data/code sections and report whether differences are confined to metadata.

## Must
- Offline evidence analysis only; no device commands, no changes to shared build trees or input binaries.
- Verify reference identity and distinguish observed facts, source-based explanation and unknown inputs.

## Decisions
- Pin all input hashes against the board reference manifest; parse bounded ELF/OAT structures, not strings grep.
- Produce machine-readable per-segment comparisons and source/file-offset citations. Never alter input binaries or add speculative metadata.
- If remote T5 bytes are unavailable, record the missing-input boundary and provide a runnable comparison command; do not fabricate a checksum attribution.
- Audit observable R155 build switches against native instruction evidence and source. Emit T3b environment settings and a separate T4 contract recommendation; unknown switches stay unknown.

## Boundaries
Allowed changes:
- benchmark/2026-09-30-t5-oat-attribution/**
- specs/t5-oat-attribution/**
- tools/spec-checks/src/lib.rs
- README.md
- .octos/KNOWLEDGE-DIGEST.md
Forbidden:
- No board commands or edits to reference/T5 artifacts, shared remote source trees, prior contracts or runtime implementations.
Out of scope:
- L2 board validation, image rebuilding without proven need, or changing frozen runtime code.

## Completion Criteria
Scenario: 精确键值与分区证据
  Test:
    Filter: t5_oat_evidence
  Given SHA-pinned ELF OAT 230 artifacts are available
  When The analyzer extracts bounded header and key-value data
  Then Every reported key and section has a byte offset and SHA provenance
  And The comparison separates header, metadata, read-only data and executable differences

Scenario: 错输入与缺证据拒绝
  Test:
    Filter: t5_oat_rejection
  Given An input has an incorrect SHA or malformed offsets or a missing candidate
  When The analyzer checks the input
  Then Corrupt input is rejected and missing evidence never becomes an equal or successful verdict

Scenario: 编译开关与不可判定项
  Test:
    Filter: t5_art_flags
  Given The SHA-pinned R155 libart and local r1 source are available
  When The audit attributes build switches to exact instructions and source lines
  Then Verified switches have binary evidence and recommended environment values
  And Unrecoverable build options remain unknown rather than inheriting an upstream default
