# Exact-player log mirror candidate (built offline, not deployed)

Previous observation: r7 reached a static video cover; absence of player messages in hilog did not establish that the player call path was unexecuted. The active logger callback differed from the default logger body. This candidate adds bounded observation at one exact player import, without changing the system logger.

`ttplayer_log_mirror.c` SHA256 `3becb0f688e9dba9f5626a8453756848dd51e2f5347c4688672de0fbe3384e8e` forwards each original call once through the reviewed exact-liblog `__android_log_vprint` ABI. It makes at most 256 mirror attempts on the existing fd2, each at most 1024 bytes including marker, tag and newline. Unsupported formats, including `%n` and positional formats, are not evaluated by the mirror. A write may block; no nonblocking guarantee is claimed.

Independent host oracle: **8/8 passed**, source SHA unchanged. ## Reproduce the offline candidate

The [recipe](build_candidate.sh) requires `SOURCE_REPO` (this checkout), `OH_NATIVE` (the existing container-visible SDK native root recorded in the original toolchain manifest), `LIBLOG_INPUT` (the exact d8ad liblog link input), and `OUT` (a fresh absolute persistent directory). Run `bash benchmark/2026-10-19-toutiao-video-playback/candidate-r8/build_candidate.sh --plan` to inspect inputs, then `--run` with those variables set. It preserves raw command/stdout/stderr/rc files; rejects input, toolchain and image drift; and checks exports and dependencies after linking. The SDK supplies `libdl.a`, discovered with the compiler. `--unwindlib=none` avoids pulling extra unwind exports from the compiler default libraries while retaining the explicit liblog dependency. The two earlier failed attempts remain in the archive.

Run `python3 benchmark/2026-10-19-toutiao-video-playback/candidate-r8/derive_ttmplayer_logmirror.py <exact-r4-player> <fresh-player-output> <fresh-proof-output>` to reproduce the player. It changes exactly 17 bytes within the 19-byte import name, retains the prior 105 cache relocations, checks 19 non-symbol string references, and compares both hash lookups for 899 names. The [CLI checks](verify_derivation.py) exercise successful derivation and six refusal cases. The `ttvideo_observation_derivation` Rust test selector invokes them.

[Archive receipt](archive-receipt.json) identifies the remotely hash-verified bundle containing exact link inputs, source snapshots, products and raw build/test evidence. Restore the archive under a persistent local directory; select `r8-build-outer-2329/build/inputs/liblog.so` as the liblog link input. The companion `source-inputs.tar.gz` in the same archive receipt contains `inputs/r4-libttmplayer.so` and exact script snapshots; its required input SHA is enforced by the derivation script. Public [text records](evidence/manifest.json) replace only the recorded local home and SDK prefixes; original bytes and hashes remain in the archive. Neither the link-only OpenSL anchor nor the link-input liblog is a deployment payload.
