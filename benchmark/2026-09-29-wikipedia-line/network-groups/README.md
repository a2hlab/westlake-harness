# BMS supplementary-group experiment for Wikipedia (#80)

The earlier assertion that `android_getaddrinfo EPERM` proves a missing AID_INET group was stronger than the evidence. A read-only 5ea snapshot confirms two resident BMS children have only group 3099 and Wikipedia's installed BMS record has `reqPermissions: []`. It does **not** prove that 3003 alone removes the DNS failure: stock OH also consumes `TLV_INTERNET_INFO` and may call `DisallowInternet()`. No live Toutiao process was available on 5ea for the requested working-network group comparison. No reference app was launched by this lane, and that comparison remains unknown.

Per explicit outer/user authorization, this delivers the smallest unconditional AID_INET experiment: preserve the BMS DAC group table, append **3003 once**, reject a malformed/full table without overwriting any entry, and let stock `SetUidGid()` perform the existing `setgroups()` call. No 3004/raw-socket or 1015/storage group is added. OH network allow/deny values, token, UID, primary GID, seccomp, and SELinux are unchanged. `WLNET` logs the UID, final count, and request internet flags so a remaining policy denial can be distinguished from failure to apply the group.

The implementation uses the **actual v3a real-work V1 host source**, not the generic `src/child_main.cpp` in the tracked V2 tree. Baseline source and its original compile/link commands are saved here. Only `appspawn_service.o` is recompiled; the remaining **16 host objects** and link inputs are unchanged. The unmodified recipe, run from its original build directory, reproduces the active host **byte for byte** (`b87fdb77...`). A first replay from a different working directory changed debug/build-ID bytes; preserving the original cwd restored the exact baseline. Candidate **d977bd15...** passed strict linking, two-build byte equality, and the NEEDED/SONAME/RUNPATH/FLAGS comparison. Full hashes are in `results.json` and `elf-audit.json`.

[HANDOFF.md](HANDOFF.md) gives cc-wiki the package, deployment command, Java-overlay ordering, expected evidence, and original-host rollback SHA. The package changes **exactly one file** from v3a/r8b. The deployer was extended to accept exactly `/system/bin/appspawn-x` in addition to declared native libraries, stage it executable (0755), and retain all prior SHA/maps/single-ART/rollback checks. Other executable paths remain refused.

Validation: actual helper compiled and exercised for 8 boundary assertions; deployment tests **8 + 18 passed**; known-answer suite **69 tests, 2 skipped, 0 failures**. Package dry-run performs no device I/O. Shared B11 lifecycle had **4 Skip**, all selectors unmatched, and is not reported as Pass. Sources and the new build are ready; **child groups, DNS recovery, and screenshots are unverified by cx-t0**. cc-wiki retains the 5ea lock and owns all activation and app tests.

Persistent base inputs are the already archived B9 source/toolchain/link-input set at `/home/alvin/westlake-oh6.1-b9-v3-74d1d6d4-source/`, documented in the B9 report's source-preservation receipts.
