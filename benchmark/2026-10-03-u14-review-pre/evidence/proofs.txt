=== N1 dlopen findings (0, 39-43) — all RTLD_NOLOAD singletons ===
Every primary is RTLD_NOW|RTLD_NOLOAD = return a handle ONLY if the lib is already mapped in the caller's ns
(cannot create a fresh ns, cannot load a new copy). Targets are always-resident route-A singletons:
  liboh_android_runtime.so  (loaded by appspawn-x / OHEnvironment init)
  liboh_adapter_bridge.so   (loaded by OHEnvironment static-init before hwui RenderThread)
  libEGL.so                 (loaded by hwui RenderThread via OH GLES init)
Two RTLD_NOW fallbacks ([0] runtime, [42] libEGL) are idempotent: dlopen of an already-mapped lib returns the
SAME handle (refcount++), no second copy. [41] is explicitly "never load a second bridge copy; reach the one the
shared runtime depends on". All failure paths are graceful (LOGE/stderr/no-op), never a crash.
