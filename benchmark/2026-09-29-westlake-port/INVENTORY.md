# B8 inventory: Westlake framework fixes mapped to route-A (read-only survey, 2026-09-29)

Status: V = verified by reading code or logs, I = inferred. ★ = relevant to the white starting window, W = relevant to Wikipedia after B6. RA/ = `bms/src/adapter/framework/`. WL/ = smali of the Westlake `adapter-runtime-bcp.jar` deployed with framework-2 on 5ea (sha 9ddf1e82), at `~/a2hlab-provision/fxwork/out-smali.orig/` (telephony-patched a3069ada in `out-smali/`). That this is the 09-27 sweep base is inferred (smali README / RESULTS cab462ff).

route-A has two Java layers: `oh-adapter-framework.jar` (BCP: OHServiceManager, PackageManagerAdapter, WindowSessionAdapter) and `oh-adapter-runtime.jar` (not BCP: AppSchedulerBridge, AppSpawnXInit). The runtime jar on the boards is produced by `bms/src/tools/devices/zigzag-apk-lightup.sh` `build_runtime_jar` (PR03 dex + smali injection + helper classes), not from a clean `bms/src` build. Port fixes into the runtime jar through the existing projection pattern (`activity/java/PackageManagerProjectionProxy.java`; `UserManagerProjectionProxy` / `StorageManagerProjectionProxy.install()` writing `ServiceManager.sCache`), which avoids rebuilding the boot image.
