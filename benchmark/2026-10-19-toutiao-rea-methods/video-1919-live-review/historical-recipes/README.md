# Historical one-off execution recipes — DO NOT BLINDLY REPLAY

These source and generated transaction files are copied byte-for-byte from the outer private persistent directory. source-pins.json binds every original and delivered SHA. They preserve useful execution code; they are not a new deployment framework or a reusable authorized entry.

The Python files are the final on-disk snapshots collected at closeout. The guarded-window script was revised after the original apply: its final SHA must not be misrepresented as an execution-time SHA for that earlier revision. Actual apply/rollback swap.sh, plan.json and result.json preserve the concrete generated operations for each transaction. Earlier review hashes remain in the icon evidence package.

They are bound to historical serial, boot, process identities, metadata, WID, source pins, lock owner and evidence locations. Never rerun against a current board by merely changing one argument. This reviewer did not execute them. Full original command stdout/stderr remains private and is indexed by the raw-command-manifest; do not substitute these scripts for raw execution receipts.
