# Wall-2 (A'=approach 4): add one DT_NEEDED to libicuuc f74827d9 -> a tiny shim libicu74compat.so that maps the 7 _74
# names tttext dlsyms to libicuuc's _72. No full-ICU rebuild; libicuuc code/exports unchanged. Mac DevEco clang; local.

## Static check (a): OHOS musl dlsym(handle) searches the handle's DEPENDENCY TREE -> the shim is reachable.
# hw248:/home/alvin/aosp-14.0.0_r1-art/external/musl/ldso/dynlink.c (OHOS musl; has dlns_/namespace):
#   do_dlsym(p,s,ra): for a real handle p (not head/DEFAULT/NEXT) -> use_deps=1; find_sym2(p,s,0,use_deps)
#   find_sym2(dso,s,need_def,use_deps): deps = use_deps ? dso->deps : 0;
#                                       for (; dso; dso=use_deps ? *deps++ : dso->syms_next) { ...lookup... }
# dso->deps is musl's FLATTENED TRANSITIVE dependency array. So dlsym(<ICU handle>, "ubrk_open_74") searches the handle's
# lib AND every transitive dep. Adding DT_NEEDED libicu74compat.so to libicuuc puts the shim in that tree. => (a) HOLDS.

## Static check (b): which handle tttext dlsyms the 7 names on.
# libtttext_lite.so brk_open (0x1aa80) dlopen()s libkryptoni18n.so->libicui18n.so->libicuuc.so and caches handles in a
# global table; the dlsym helper (0x1aba0) loads a cached handle from [0x44000..] and bl dlsym (0x1abc4). The 7 names
# (ubrk_open/close/first/next/setText, u_charType, u_hasBinaryProperty) are all libicuuc COMMON-layer symbols, so the
# handle is the libicuuc handle -> the shim is a DIRECT dep (one hop). Even if a name were dlsym'd on the libicui18n
# handle, libicui18n NEEDED libicuuc (verified) and musl's deps is the transitive closure, so libicui18n -> libicuuc ->
# shim still resolves. => reachable either way.

#   before: f74827d992d25ffe (f74827d9)   NEEDED = libc++.so, libc.so   (.dynamic 27 entries)
#   after : 9b36b989dd10...            NEEDED = libicu74compat.so, libc++.so, libc.so   (.dynamic 28 entries)

#   SIZE: 2,260,360 -> 2,547,137 (+286,777). This growth is inherent, NOT extra code: .dynstr is 157 KB with only 1 byte
