# Hollow metasec stub (#48) — evidence
date: 2026-09-26   target: toutiao libmetasec_ml.so (arm64-v8a)

## Why a stub (no sweet spot)
Partial symbol closure -> metasec half-loads -> probabilistic sixth exit.
Full closure -> metasec fully loads, runs real init, ~7s SIGSEGV reading
Bionic pthread layout on musl (Bionic-bound residual). #41: metasec is not
required for feed+articles. So: hollow no-op libmetasec_ml.so, no real init.

## App-side native ABI metasec must satisfy (the WHOLE surface)
1) real libmetasec_ml.so exports exactly ONE dynamic symbol:
      FUNC JNI_OnLoad
2) no other APK lib DT_NEEDs libmetasec_ml.so (empty native-import surface):
     (none)
3) app declares exactly ONE native backed by metasec (single dispatcher):
     class  ms.bd.c.m
     method public static native Object a(int,int,long,String,Object)
     JNI    (IIJLjava/lang/String;Ljava/lang/Object;)Ljava/lang/Object;
     -> mangled short name Java_ms_bd_c_m_a (one native in class => short form)
     (com.bytedance.mobsec.metasec.ml.* are pure-Java wrappers, 0 natives)
