# G26 input originals archive

The fixed G24 native-route comparison, its original LLVM receipts, the host build-readiness packet and independent G26 static review are preserved in one remote archive. The local and remote SHA256 values were compared after upload. See `remote-archive.json` for the exact persistent location and size. External ELF/APK inputs and future candidate builds are excluded; this receipt does not establish a successful build or game launch.

Independent review reran the route checker against 1,119 raw hashes and the host inspector against 255 local observations. Of the latter, 209 had previous pins and 46 are current observations, not retrospective proof of historical linker input selection. Mediandk visibility remains a candidate/runtime check. No evidence requires additional resident-runtime or audio GLOBAL publication in G26.
